# RF4 Companion Data

Anonymisierte Wochenrekorde aus Russian Fishing 4 für den RF4 Companion: alle drei Wochentabellen (Rekorde, Light, Bottom light) aller Regionen, jeweils mit dem Zeitpunkt, an dem ein Eintrag zuerst gesehen wurde. Spielernamen sind nicht enthalten.

Anonymised weekly records from Russian Fishing 4 for RF4 Companion: all three weekly tables of all regions, each entry with the time it was first seen. Player names are not included.
